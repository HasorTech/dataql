# v5.0.1 (2026-11-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dataway-embedded</artifactId>
    <version>5.0.1</version>
</dependency>
```

## 更新内容

### 依赖升级

- JDBC 元数据和平台数据访问模块使用的 dbVisitor 从 `6.8.2` 升级至 `6.8.3`。
- Hasor 集成模块和独立控制台使用的 Hasor 从 `5.3.0` 升级至 `5.4.0`。

### 文档与构建

- 接入 Hasor Tech 导航，提供独立的文档入口和侧栏。
- 统一 Gradle Wrapper 和构建发布脚本，将 Maven POM 元数据集中到根目录的 `pom.json`。
- 将剩余 JUnit 4 测试迁移到 JUnit Jupiter，测试完成后自动生成 JaCoCo 覆盖率报告。
- 调整 Hasor Boot 测试，先完成配置，再启动应用。
