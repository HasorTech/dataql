# v5.0.1 (2026-11-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dataway-embedded</artifactId>
    <version>5.0.1</version>
</dependency>
```

## Changes

### Dependency upgrades

- Upgraded dbVisitor for JDBC metadata and platform data access from `6.8.2` to `6.8.3`.
- Upgraded Hasor for the integration module and standalone console from `5.3.0` to `5.4.0`.

### Documentation and build

- Added a dedicated documentation entry point and sidebar within Hasor Tech navigation.
- Standardized the Gradle Wrapper and build and release scripts. Maven POM metadata is maintained in the root `pom.json`.
- Migrated the remaining JUnit 4 tests to JUnit Jupiter and configured JaCoCo coverage reports to run after tests.
- Updated Hasor Boot tests to configure the application before starting it.
