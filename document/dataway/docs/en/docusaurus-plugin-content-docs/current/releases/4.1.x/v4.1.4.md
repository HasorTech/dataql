# v4.1.4 (2020-04-30)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-dataway</artifactId>
    <version>4.1.4</version>
</dependency>
```

## 更新内容

- 新增
  - 接口可以跨域访问。
  - Dataway 增加 `CompilerSpiListener` 扩展点，可以自定义接口脚本的编译过程。
  - 增加 `PreExecuteChainSpi` 扩展点，可在脚本执行前干预。配合 `ResultProcessChainSpi` 可实现缓存和权限控制。
  - 增加 `ResultProcessChainSpi` 扩展点，可对脚本执行结果进行二次处理。
  - Dataway 新增 `DatawayService` 界面配置的接口可以在本地应用上用代码发起调用了。
  - [Issue 13](https://github.com/zycgit/hasor-old/issues/13) 支持配置多个数据源，每次脚本查询使用一个数据源。
  - [Issue I1F0ZB](https://gitee.com/zycgit/hasor-old/issues/I1F0ZB) Dataway 新增 Oracle 的支持。

- 优化
  - [Issue I1EUAL](https://gitee.com/zycgit/hasor-old/issues/I1EUAL) 改进 Dataway 在处理 GET 请求时，多个同名参数获取的问题。
  - 之前只能拿到数组形态，在于 POST 模式进行对比的时容易产生奇异造成认为是 Bug 的假象。
  - Dataway UI 界面中模式切换会因为 `//` 但行注释问题产生一些不友好的用户体验。现改成 /**/ 多行注释方式。

- 修复
  - [Issue I1EM2V](https://gitee.com/zycgit/hasor-old/issues/I1EM2V) Dateway 4.1.3 版本资源文件缺失问题。
  - [Issue I1FD95](https://gitee.com/zycgit/hasor-old/issues/I1FD95) Dataway 修复 spring boot context_path 不支持的问题。
  - 修复禁用管理界面后调用接口时，因脚本运行环境未初始化引发的空指针异常。
