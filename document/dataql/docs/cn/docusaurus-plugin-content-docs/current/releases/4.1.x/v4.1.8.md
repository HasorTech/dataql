## 更新内容

- 新增
  - [PR 8](https://gitee.com/zycgit/hasor-old/pulls/8) 合并来自社区的 @@mybatis 的能力，通过 @@mybatis 可以给 SQL 增强动态SQL能力。

- 优化
  - DataQL 的 Maven 插件对 Maven 的依赖从 3.3.9 降低到 3.3.3。
  - [Issue I1HW0C](https://gitee.com/zycgit/hasor-old/issues/I1HW0C) 增加一个 Hint 用来可以设定查询分页时 currentPage 的默认启始数字。
