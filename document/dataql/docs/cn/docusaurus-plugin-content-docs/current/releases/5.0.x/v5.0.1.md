## 更新内容

### 依赖升级

- 引擎使用的 Cobble 从 `5.0.4` 升级至 `5.0.5`。

### 文档与构建

- 接入 Hasor Tech 导航，提供独立的文档入口和侧栏。
- 统一 Gradle Wrapper 和构建发布脚本，将 Maven POM 元数据集中到根目录的 `pom.json`。
- 将剩余 JUnit 4 测试迁移到 JUnit Jupiter，测试完成后自动生成 JaCoCo 覆盖率报告。
