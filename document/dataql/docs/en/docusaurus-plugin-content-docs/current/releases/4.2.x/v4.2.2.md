## 更新内容

- 新增
  - dataql-fx 增加去重函数。`CollectionUdfSource.uniqueBy`。
  - [PR 16](https://gitee.com/zycgit/hasor-old/pulls/16) 增加 `@@mybatis` 对 `<trim>`、`<set>`、`<where>` 标签的支持（小牧zzz `13507502@qq.com`）

- 优化
  - hasor-dataql Finder 使用机制优化，方便后面 import 和第三方 ioc 集成。
  - [Issue 13](https://github.com/zycgit/hasor-old/issues/13) 提供局部 Hint 能力，通过局部 Hint 切换数据源不在是梦了

- 修复
  - [Issue I1UERS](https://gitee.com/zycgit/hasor-old/issues/I1UERS) 修复两个数值相减错误
  - [Issue I22MZW](https://gitee.com/zycgit/hasor-old/issues/I22MZW) 修复三元运算符操作结果错误
  - [Issue 78](https://github.com/zycgit/hasor-old/issues/78) 优化 `Cannot resolve plugin net.hasor:dataql-maven-plugin:xxxx` 的问题
